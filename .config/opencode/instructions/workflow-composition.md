# Workflow Composition

- Clarify Intent is a mandatory preflight before planning or implementing any feature, bugfix, refactor, or behavior change.
- Invoke `clarify-intent` before Superpowers workflow skills, including brainstorming and systematic debugging. If intent is already clear, ask nothing and continue immediately.
- After the intent preflight, Superpowers owns workflow selection and sequencing.
- Ponytail minimizes implementation scope and code shape within required workflow gates.
- Ponytail must not remove required planning, debugging, testing, review, or verification.
- Task-specific output requirements override Ponytail brevity.
- If Ponytail is already active, do not reload its main skill.
